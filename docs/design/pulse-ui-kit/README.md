# Pulse UI kit (hardware UI)

Source of truth for the hardware UI, from `pulse-ui-kit.zip` (2026-10-10):
`PULSE_UI_DESIGN.md` (the spec), `tokens.json`, and the four mockup
screenshots. The kit's reference React bundle is not checked in; the app
implements the spec in its own components (`src/app/hardware.css`, scoped by
`.pulse-hw`). Rollout plan: `openspec/changes/hardware-ui/`.
