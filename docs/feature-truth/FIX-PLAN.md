# Fix plan from the feature truth audit (2026-11-12)

Every row is a confirmed gap between what Pulse says and what the production code (main `4a3b5ba`) does. Two reviewers looked at each: one found it, one tried to disprove it. The full record, with evidence lines, is `audit-2026-11-12.json` in this folder.

## Rules for whoever fixes these

1. Work on a branch off `develop`. Open a pull request against `develop`. Never merge it, never push to `main` or `develop`, never deploy, never run anything against the production Convex deployment. The owner merges.
2. Before changing anything, check the gap still exists on `develop`. If it is already fixed, say so in the pull request and move on.
3. `copy` fixes change words only. Make the words say what the code does today. Do not delete a feature from the price list when a truthful, narrower sentence exists.
4. `bugfix` items follow the fix-a-bug path: find the cause, fix it, and add a test that fails before the fix and passes after. Do not weaken or delete an existing test.
5. Anything marked high risk (payments, charging a card, access control, deletes, wages) is NOT built from this file. Batch B5 is written up first and waits for the owner.
6. Run `npx tsc --noEmit` (not incremental), `npm run lint` and the test suite before pushing. Three tests were already failing on `main` before this work: `lib/agentScope`, `marketing/results`, and a time-of-day case in `outreachCalls.test.ts`. Do not count those against the change, and do not fix them here.
7. In the pull request body, list every id from this file that the change covers, with one line on what changed and the test that proves it. List the ids you skipped and why.
