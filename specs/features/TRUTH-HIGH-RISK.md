## Corrections to the audit
- **Auto-cancel:** the reviewer's extra ask, "add `isPublic &&` to step 4", is already done on `develop` (`convex/automation.ts:256`). Only the pricing-hidden guard is missing.
- **Discount codes:** "never expire" is partly wrong. While the 28-day promo row exists and is on, it hides the permanent code. The permanent code only works once someone switches the promo off.
- **Plan gates, exports:** the open exports are deliberate (`convex/exports.ts:10-12`).
- **Payroll, prepaid hours:** the iOS app is not in this repository, so the audit's iOS notes could not be checked.

## Rules for every fix
Build on a branch off `develop` and test on staging (`fiery-cricket-350`). Promote to `main` and deploy production only when the owner asks. Each fix keeps its own `eval.md` and every check must PASS before merging.
