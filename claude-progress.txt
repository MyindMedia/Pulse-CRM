ARCHITECTURE
================================================================
Pulse is a multi-tenant studio operating system for recording studios: a Next.js 16
App Router web app (React 19, TypeScript strict, Tailwind v4) on Netlify, a Convex
backend (schema, queries, mutations, actions, crons, HTTP webhooks; money in integer
cents; every record scoped by orgId), Clerk auth (no publishable key = demo mode),
Stripe for platform billing and Stripe Connect for studio payments, Cloudflare R2 for
files (some uploads still use Convex storage), plus Resend, Zuops/GHL, Plaid, Google,
Bland and AI providers. Three surfaces: public (marketing, booking, token-link pages),
the studio app (src/app/(app)), and the platform owner's agency console (src/app/agency).
The native iPhone/macOS apps live in a separate repo and read Convex through sync.*.

Permission engine: convex/lib/access.ts runs three checks on every call: may this
person (role/capability), did this workspace buy it (plan entitlement), is the module
switched on. Plans: Core $149, Growth $297, Max $699; 14-day card trial; 365-day beta.

HOW TO RUN AND TEST
================================================================
./init.sh                 base check, npm ci if needed, tsc, core tests, dev server on :3147
SMOKE=full ./init.sh      full suite
START_DEV=0 ./init.sh     static checks only
npx tsc --noEmit | npx vitest run | npm run lint | npm run check
npx next build            builds without codegen ("npm run build" runs convex codegen
                          first and needs a deployment)

The dev server needs NEXT_PUBLIC_CONVEX_URL pointing at a NON-PRODUCTION deployment.
WARNING: src/lib/convex-url.ts falls back to the PRODUCTION backend when the variable is
unset. Never run "next dev" or a local build for testing without it. init.sh refuses to.
A fresh worktree has no .env.local and no node_modules.
